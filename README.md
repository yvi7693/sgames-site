# S.Games — сайт студии (вариант 5)

Статический сайт без сборки: HTML + CSS + JS. Главная посвящена игре **Fluffy Paw**, сайт при этом остаётся сайтом студии S.Games.

## Запуск локально
```bash
python3 -m http.server 5173
```
Открыть `http://localhost:5173`.

## Деплой
- Vercel, проект `sgames-site`: каждый пуш в `main` публикуется автоматически (production), пуши в другие ветки дают preview-ссылки.
- GitHub Pages: https://yvi7693.github.io/sgames-site/ — публикуется из ветки `main` (корень), тоже автоматически при каждом пуше. Файл `.nojekyll` отключает обработку Jekyll.
- Сборка не нужна: корень репозитория — корень сайта.
- Адреса `*.vercel.app` в части сетей (в том числе в РФ) блокируются — для публичного запуска нужен свой домен студии, подключённый к проекту в Vercel.

## Страницы
| Файл | Что |
|---|---|
| `index.html` | Fluffy Paw: трейлер во весь экран → при прокрутке сжимается в окно, появляются меню, хук и кнопка вишлиста; чашка с паром у хука; фичи «Дорожка из лапок» с номерами в кружках, следы доходят до футера; Discord на плашке; повтор призыва; «Made by S.Games» с логотипом и спящим котиком |
| `about.html` | Team: общее фото студии (наведение на человека — кто это) и текст |
| `contacts.html` | Месседж о сотрудничестве, карточки Discord и Email, иконки соцсетей |
| `press.html` | Пресс-кит, factsheet первым блоком |
| `privacy.html` | Политика конфиденциальности |

## Файлы
- `style.css` — вёрстка и анимации.
- `palette.css` — палитра «Лазурь и сливки» (синий из «Лазури и ванили», бежевый из «Глубины лого») и тёмная тема. Правило цвета: белый — меню; синий — подвал, кнопки, текст; бежевый — оформление страницы игры.
- `site.js` — меню, тема, трейлер, дорожка из лапок, видео, копирование почты.

## Заполнение
- `.ph`, `.ph-text`, `[В СКОБКАХ]` — плейсхолдеры, убрать класс, когда контент готов.
- Видео положить в `assets/video/`: `trailer.mp4` (+ `trailer.webm`), `feature-1..3.mp4`. Слот сам покажет видео после загрузки.
- Ссылки Steam, Discord и почта — объект `SITE` в начале `site.js`.
- Превью ссылок для соцсетей: `assets/img/og-fluffy-paw.jpg`, `assets/img/og-sgames.jpg` (пока нет).
- Координаты людей на общем фото команды — `--x/--y` у `.person` в `about.html`.
